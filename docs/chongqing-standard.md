## 图形、文字与颜色

新增符号位于 `js/crt-symbols.js`，原有服务设施和方向符号继续复用 `js/icons.js`。新增几何均为自包含 SVG 路径与基础图形，没有字体字符图标、位图、远程图片或外部 `<use>` 引用。`SignCRTSymbols.get(id)` 返回 `{name, vb, body}`；未知 id 返回 `null`，由调用端回退原图标库。

禁止图形覆盖禁止吸烟、抛物、跳下、倚靠、堆放、丢弃废弃物、坐卧、触摸、携带宠物、通过、玩耍、翻越、探头、随地吐痰、跳跃。警告图形覆盖注意安全、触电、电缆、碰头、夹手、坠落、缝隙、滑倒。危险品矩阵另含气球、放射性、桶装危险液体、易燃物、枪械刀具、爆炸物、烟花爆竹、有毒腐蚀物八类。

消防设备包含火灾报警按钮、火灾报警电话、消火栓、灭火器箱、气体消防控制盘、消防主机、气体消防主机七类。后三类源大样以文字为主，附加的控制盘图形属于编辑器辅助示意。

标准 3.4（PDF 17）及条文说明（PDF 176）以 PANTONE 色卡为颜色依据。CRT 行业色为348C（PDF 14）；进站/换乘采用白底或线路色，出站信息采用012C黄，位置确认采用432C深灰；默认参考线路色按重庆线路色板选用。用户自建虚构线路使用自己的线路颜色，添加相关标识时保留自定色。安全标志引用 GB 2893，没有在该条另列红/黄专色号。网页的 HEX/RGB 只是显示近似值，不能当作印刷专色校色结果。新增禁止图形采用红色框/斜杠、黑色内容；警告采用黄底黑图，保留在矩形牌面内。

正文的字号和 mm 对应实际成品尺寸；编辑器沿用行高缩放的几何体系，以模板牌面的宽高比统一缩放。禁止和警告的代表尺寸为200×300，正文中文80pt、英文47pt；消防设备主牌400×150，正文中文130pt、英文81.5pt。设施牌的参考横幅高320（上下各60、符号200），卫生间/哺乳室横幅高240（上下各40、符号160），图文间距60；不同尺寸依牌面比例缩放。

标准文字章节（PDF 15）区分中文微软雅黑、拼音与美式英语Helvetica、数字Frutiger，并允许加粗。编辑器仍使用仓库现有思源黑体与西文字体栈，属于屏幕可用的字体替代，不附加来源不明的字体文件。条文说明 3.3.1 也允许根据排版效果使用常规或加粗字体。

## 编辑器实现边界

本次提供矩形牌面的内容、比例、颜色和可编辑示例，继续遵守不可变状态和 metrics/draw 共用几何的架构。`guide`、`station`、`facility`、`information`、`route`、`notice` 是软件内的版式分类，同一版式可承载多个标准标志类型；它们不是新增标准术语。

当前线路图使用可编辑的站点数据，可通过 `routes.js` 新建虚构线路，填写各站中英文名、编号、换乘、本站和运行方向，保存为独立线路文件或本地线路。工具不接入真实运营、票价或班次服务。参考预设中的默认名称用于检查排版；选用自建线路后，新标识按当前线路和车站填入相关内容。

**自建和内置线路图中的换乘表现仍是简化实现，不能宣称严格按 PDF 还原。** 图4.1.9-1～4（PDF29～32／正文19～22）的换乘站旁有圆形换乘图形及逐条线路的圆形编号标记；普通站站号位于节点圆内，本站采用放大的线路号／站号分隔圆和确认横带。图4.1.11-1～2（PDF34～35／正文24～25）的横向列车运行方向图也包含这些站点及换乘标记。当前自建图采用普通圆点、圆外编号和换乘文字，虽可按已定义外线分别着色，仍未实现上述完整符号与排版；内置线路图同样经过简化。

图4.8.3-1～2（PDF69～70／正文59～60）的互联互通图另有普通／直快服务运行带、不同停站连接符及逐站线路号／站号信息；图4.8.5（PDF72／正文62）也区分相应运行和停站关系。目前线路数据和绘制尚未实现这些服务类型。附录H的 FZ-04／FZ-05（PDF122～123／正文112～113）仅作为牌体尺寸与安装参考，不能用来证明图内换乘内容符合标准。

当前 81 款预设每次添加都会建立独立牌面，内部均为基础元素的组合；横门楣与竖站名牌通过顶部卡片切换，各自保留尺寸与布局。简单横牌共享原有元素排版；其他牌面的文字、符号、线路、站点圆点、色块及分隔线通过位置和尺寸组合，可分别编辑和移动。预设行保存参考比例和当前比例，用户可修改或恢复；我的预设保留比例、定位盒、底色与线路图数据。旧整牌数据仅为兼容保留，并提供转为基础元素的操作。

历史地图和时刻表仅保留恢复旧项目所需的目录及渲染。旧地图中的街区、建筑和疏散几何均为示意，工具没有建筑平面导入、地图数据或自动路径规划功能；它们不作为当前新增预设提供。

为 Minecraft 等虚构场景制作标识时，先建立线路，再选择当前站并添加各种预设。共享的线路与当前站信息随项目保存；切换当前站只影响以后添加的标识，既有牌面不会批量改写。项目 JSON 保存整个工作区的独立牌面，SVG／PNG 只输出当前牌面或当前行。入门步骤见 [虚构线路制作](fictional-lines.md)。
